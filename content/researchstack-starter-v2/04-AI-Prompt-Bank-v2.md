# AI Prompt Bank

Use AI to structure, check, and speed up work. Do not use it to invent citations, data, ethics approvals, clinical facts, or supervisor instructions.

## Project Idea Prompt

I am an Australian medical student interested in [specialty/topic]. My experience level is [beginner/intermediate], and I can spend [hours] per week. Generate 10 realistic research project ideas. For each, classify the project type, expected output, likely approvals issue, ideal supervisor type, first action, and biggest risk.

## Project Selector Prompt

Compare these possible projects and score them for beginner fit, time to output, approval complexity, supervisor dependence, and CV value. Recommend the best project to start with and explain why:

[paste project ideas]

## Supervisor List Prompt

Create a strategy to find 20 potential supervisors for [specialty/topic] in [city/university/hospital]. Include where to search, what keywords to use, what details to record, and how to prioritise them.

## Outreach Email Prompt

Draft a concise research outreach email to [doctor/researcher]. I am a [year] medical student at [university]. I am interested in [topic]. I found their work on [paper/project]. I can help with [tasks]. Tone: respectful, specific, Australian medical student, not exaggerated.

## Supervisor Meeting Prompt

Create a 15-minute meeting agenda for discussing a potential [project type] project on [topic]. Include questions about project question, approvals, data access, student role, authorship, timeline, output target, and next action.

## Case Report Prompt

Create a case report plan from these clinical notes. Do not include identifiable details. Structure it into: possible title, clinical timeline, missing information, literature search terms, possible figures/tables, CARE checklist items to consider, and draft learning points.

[paste de-identified notes]

## Audit/QI Prompt

Help me turn this clinical problem into an audit/QI project. Identify possible standards, audit criteria, inclusion/exclusion criteria, data fields, process/outcome/balancing measures, possible tables/figures, and a poster abstract structure.

[paste problem]

## Retrospective Study Prompt

Create a retrospective chart review protocol skeleton for this research question. Include study design, setting, inclusion/exclusion criteria, exposure, outcomes, variables, data dictionary, missing data plan, table/figure plan, and STROBE items to consider.

[paste question]

## Literature Search Prompt

For this research question, create search blocks, synonyms, MeSH terms, and PubMed-style search strings. Provide broad, balanced, and narrow versions. Do not claim the search is complete.

[paste question]

## Meta-Analysis Feasibility Prompt

Assess whether this topic is suitable for meta-analysis. Consider whether outcomes are comparable, effect sizes can be extracted, heterogeneity is likely, and statistical support is needed. Give a recommendation: narrative review, systematic review, or meta-analysis.

[paste topic and included study types]

## Table/Figure Prompt

For this [project type], propose the exact tables and figures needed for a manuscript or conference poster. For each table/figure, include purpose, required data, suggested format, and the manuscript section it supports.

## Abstract Prompt

Draft a structured abstract from these notes. Use Background, Aim, Methods, Results, Conclusion. Clearly mark missing data. Do not invent results or numbers.

[paste notes]

## Discussion Prompt

Using these results and key papers, draft a discussion structure. Include main finding, comparison to literature, implications, limitations, and future work. Do not overstate causality.

[paste results and key papers]

## Cover Letter Prompt

Draft a journal cover letter for this manuscript. Include title, article type, why the work matters, why it fits the journal, originality statement, author approval statement, and ethics/consent/governance wording placeholder.

[paste manuscript details]

## Reviewer Response Prompt

Turn these reviewer comments into a response table with columns: reviewer comment, response, change made, manuscript location. Keep tone respectful and precise.

[paste comments]

## CV Evidence Prompt

Turn this research contribution into CV bullets without overstating my role. Create versions for: application form, CV, interview answer, and LinkedIn.

[paste contribution details]
