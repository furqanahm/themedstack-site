# Project-Type SOPs

## Case Report SOP

### When To Choose It

Choose a case report when there is:

- unusual presentation
- rare complication
- diagnostic challenge
- management lesson
- adverse effect
- systems/communication lesson
- imaging/pathology finding with clear teaching value

### Before Starting

Confirm:

- supervisor
- patient consent/local process
- de-identification
- target journal/conference
- author roles
- timeline

### Student Tasks

- build clinical timeline
- perform focused literature search
- create comparison table of similar cases
- draft introduction
- draft case presentation
- draft discussion
- format references
- prepare CARE checklist if required

### Tables/Figures

Possible assets:

- timeline table
- imaging figure
- investigation trend table
- literature comparison table
- learning points box

### Manuscript Sections

Title:

- include condition/presentation and "case report" if journal expects it

Abstract:

- background
- case summary
- conclusion

Introduction:

- why the case matters
- what is known
- what lesson this case adds

Case Presentation:

- patient details only as needed
- symptoms
- relevant history
- examination
- investigations
- diagnosis
- treatment
- outcome/follow-up

Discussion:

- compare with existing literature
- explain mechanism/clinical lesson
- discuss uncertainty
- limitations

### Common Mistakes

- case is not novel or educational
- no consent/local approval process
- too much unnecessary clinical detail
- weak discussion
- no comparison to literature
- submitting to predatory journals

## Audit / QI SOP

### When To Choose It

Choose audit/QI when there is:

- a measurable clinical process
- an existing standard/guideline/policy
- accessible data
- a supportive department
- a possible local presentation or poster

### Core Question

Are we meeting standard X in patient/process Y over time period Z?

### Before Starting

Confirm:

- audit/QI/research classification locally
- governance or registration
- data access
- supervisor
- standard/guideline
- target output

### Student Tasks

- identify standard
- build audit criteria table
- create data collection sheet
- collect/extract data if permitted
- summarise baseline results
- build charts
- help design intervention
- write abstract/poster

### Tables/Figures

Expected assets:

- audit criteria table
- baseline compliance table
- bar chart of compliance by criterion
- run chart if repeated measures
- PDSA cycle table if QI
- before/after comparison table

### Manuscript / Poster Sections

Background:

- clinical importance and standard

Aim:

- measure or improve a defined process

Methods:

- setting
- standard
- sample
- data source
- measures
- analysis
- governance

Results:

- compliance rates
- gaps
- variation
- before/after if applicable

Discussion:

- why gaps exist
- intervention
- limitations
- sustainability

### Common Mistakes

- no standard
- unclear denominator
- poor data definitions
- no governance
- results shown without practical improvement

## Retrospective Observational Study SOP

### When To Choose It

Choose this when:

- data already exists
- cohort can be identified
- variables are available
- approvals are realistic
- supervisor can help with analysis

### Core Question

In population P, is exposure/feature X associated with outcome Y?

### Before Starting

Confirm:

- design type
- data source
- approval/governance
- inclusion/exclusion criteria
- primary outcome
- variables
- statistical support

### Student Tasks

- draft protocol
- create data dictionary
- build extraction sheet
- perform literature search
- help with data extraction if allowed
- build Table 1
- draft methods/results

### Tables/Figures

Expected assets:

- flow diagram of included/excluded records
- Table 1 baseline characteristics
- outcome table
- regression/association table if applicable
- subgroup table if justified

### Manuscript Sections

Methods:

- retrospective design
- setting and dates
- cohort definition
- inclusion/exclusion
- variables
- outcome definitions
- statistical analysis
- ethics/governance

Results:

- sample selection
- baseline characteristics
- main outcomes
- secondary outcomes
- missing data

Discussion:

- main finding
- compare to literature
- clinical implication
- limitations: selection bias, missing data, confounding

### Common Mistakes

- collecting too many variables
- vague outcome definition
- no data dictionary
- underpowered analysis
- overclaiming causation

## Literature / Scoping Review SOP

### When To Choose It

Choose this when:

- topic is broad or emerging
- aim is to map evidence
- meta-analysis is not appropriate
- you need to understand a field

### Student Tasks

- define question
- build search blocks
- search databases
- screen titles/abstracts
- extract study details
- summarise themes
- build evidence table

### Tables/Figures

Expected assets:

- search strategy table
- included studies table
- theme table
- evidence gap table
- flow diagram if systematic enough

### Common Mistakes

- topic too broad
- no search log
- no inclusion/exclusion criteria
- descriptive summary with no structure

## Systematic Review SOP

### When To Choose It

Choose systematic review when:

- question is narrow
- enough studies exist
- inclusion/exclusion criteria are clear
- two reviewers are available
- supervisor understands methods

### Core Assets

- protocol
- search strategy
- screening record
- extraction form
- risk of bias assessment
- PRISMA flow diagram
- PRISMA checklist

### Tables/Figures

Expected:

- PRISMA flow diagram
- study characteristics table
- risk of bias table
- outcomes summary table

### Common Mistakes

- doing it alone without second reviewer
- no protocol
- incomplete search strategy
- no risk of bias assessment
- treating it like a narrative essay

## Meta-Analysis SOP

### When To Choose It

Only choose meta-analysis when:

- outcomes are comparable
- enough studies report usable quantitative data
- effect sizes can be calculated
- there is statistical support
- heterogeneity can be assessed

### Extra Assets

- effect size extraction table
- forest plot
- heterogeneity statistics
- sensitivity analysis if appropriate
- funnel plot if appropriate

### Common Mistakes

- pooling studies that should not be pooled
- mixing incompatible outcomes
- not understanding heterogeneity
- making conclusions stronger than the evidence

## Survey / Medical Education SOP

### When To Choose It

Choose this when:

- there is a defined educational/workforce question
- population is reachable
- questionnaire is clear
- ethics/governance is sorted

### Tables/Figures

Expected:

- participant characteristics
- response rate
- main response table
- Likert plot/bar chart
- theme table for free-text responses

### Common Mistakes

- weak survey design
- low response rate
- too many questions
- no ethics plan
- overinterpreting convenience samples
