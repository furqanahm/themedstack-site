# ResearchStack Starter v2

This is the corrected direction for the product.

ResearchStack Starter should not be a pile of PDFs. It should be a workbook-led operating system that guides a medical student from:

1. "I need research but do not know where to start"
2. to finding supervisors
3. to choosing the right project type
4. to understanding what that project actually involves
5. to building tables, figures, results, and manuscript sections
6. to preparing emails, cover letters, formatting, reporting checklists, and submission files
7. to logging everything as CV evidence

## Product Architecture

### 1. ResearchStack Starter Workbook

This is the main product interface.

File:

- `ResearchStack-Starter-Workbook-v2.xlsx`

It includes tabs for:

- Start Here
- Project Selector
- Supervisor CRM
- Outreach Pipeline
- Project Pipeline
- Case Report Builder
- Audit/QI Builder
- Retrospective Study Builder
- Literature Review Builder
- Systematic Review / Meta-Analysis Builder
- Tables and Figures Planner
- Manuscript Builder
- Submission Pack
- AI Prompt Vault
- CV Evidence Log
- 8 Week Sprint

### 2. Operating Manual

This explains the system and how to move through the workbook.

### 3. Project-Type SOPs

This is where each research paper type is explained properly:

- case report
- audit / quality improvement project
- retrospective observational study
- literature / scoping review
- systematic review
- meta-analysis
- survey / medical education project

Each type needs:

- when to choose it
- what approvals may be needed
- what the student can realistically do
- what data is required
- expected tables and figures
- manuscript structure
- common mistakes
- AI prompts
- output pathway

### 4. Publication Submission Pack

Includes:

- cover letter template
- supervisor update emails
- authorship confirmation email
- journal formatting checklist
- conference abstract checklist
- revision response structure

### 5. AI Prompt Bank

Prompts organised by workflow stage:

- project idea
- supervisor email
- meeting prep
- project protocol
- data dictionary
- search strategy
- table/figure planning
- abstract drafting
- manuscript drafting
- cover letter
- reviewer response
- CV bullets

## The Core Promise

ResearchStack Starter helps a medical student create a legitimate research pipeline and move one project towards a real output.

It should not promise publication. It should promise:

- clarity
- structure
- better emails
- better project choice
- fewer stalled projects
- stronger CV evidence
- a realistic route from idea to submission
