# Abstract Template

## Title

[Clear, specific title]

## Background

1-2 sentences:

- What is the problem?
- Why does it matter?
- What gap does this project address?

## Aim

This project aimed to [measure/evaluate/describe/compare/improve] [topic] in [population/setting].

## Methods

Include:

- design
- setting
- population
- time period
- data source
- key variables
- analysis method
- approval/governance if relevant

## Results

Include:

- sample size
- main numerical findings
- secondary findings
- important comparisons

Do not invent results if data is not complete.

## Conclusion

Include:

- main takeaway
- implication
- next step

## Before Submitting

Check:

- word count
- author list
- affiliations
- supervisor approval
- governance/ethics wording
- conference formatting
- conflict of interest
- references if required
