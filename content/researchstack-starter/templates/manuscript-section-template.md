# Manuscript Section Template

## Title Page

- title
- authors
- affiliations
- corresponding author
- word count
- abstract word count
- keywords

## Abstract

Use the target journal format.

## Introduction

Paragraph 1:

- establish clinical/research problem

Paragraph 2:

- summarise current evidence

Paragraph 3:

- identify gap and aim

## Methods

Include:

- study design
- setting
- participants/sample
- inclusion/exclusion criteria
- data source
- variables
- outcomes
- statistical analysis
- ethics/governance

## Results

Include:

- sample description
- primary findings
- secondary findings
- tables/figures

## Discussion

Paragraph 1:

- main finding

Paragraph 2:

- comparison to literature

Paragraph 3:

- implications

Paragraph 4:

- limitations

Paragraph 5:

- conclusion/future work

## Tables and Figures

- Table 1: baseline characteristics
- Table 2: main results
- Figure 1: flow diagram/process/results

Check target journal style.
